# Сборка перевода руководства по ремонту

Инструменты, которыми собран [`../`](../README.md). Нужны, чтобы восстановить картинки на другой машине или пересобрать
страницы после правки перевода.

| Файл | Что делает |
|---|---|
| `pyi_extract.py` | разбирает PyInstaller-exe из сборки «Voyah Zhiyin 2024 v0.1» **без запуска**: `python pyi_extract.py list <exe>` выводит оглавление архива, `python pyi_extract.py x <exe> <папка>` извлекает файлы. Данные лежат в `<папка>/site/` |
| `parse.py` | китайские `site/pages/*.html` → блочная модель `model.json` и уникальные сегменты `segments.json` |
| `translations.json` | **память переводов** `{китайский сегмент: русский перевод}`, 10 377 строк. Единственный источник русского текста: чтобы исправить перевод, правьте его здесь и пересобирайте |
| `render.py` | `model.json` + `translations.json` → `../NN-раздел/*.md`, оглавления разделов, копия картинок в `../images/` |

## Как пересобрать и восстановить картинки

```sh
# 1. извлечь исходник (exe не запускается)
python pyi_extract.py x "Руководство по ремонту электромобиля Voyah Zhiyin 2024 v0.1.exe" extracted
# 2. указать путь к site/ и собрать
export SM_SITE="$PWD/extracted/site"      # PowerShell: $env:SM_SITE = "...\extracted\site"
python parse.py && python render.py
```

`render.py` пересоздаёт только папки разделов `NN-*` (`README.md`, `GLOSSARY.md` и `_build/` не трогает) и копирует
`images/`, только если этой папки ещё нет. Сборка детерминированная: повторный прогон на той же памяти переводов даёт
те же файлы байт в байт (проверено 2026-09-27).

sha256 исходного exe: `7293659ce63b47f446f7dfb51ff2bad781f19db432af36e0ef41458fb75f5b11`.
