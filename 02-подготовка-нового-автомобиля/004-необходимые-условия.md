# Необходимые условия

> Подготовка нового автомобиля › Технология подготовки  
> Оригинал: `必备条件` · [dongcheyun 56746](https://dongcheyun.com/p/56746), страница `87e23667565c4108938ceb6617ada47d` · [оглавление](../README.md)

Освещение в зоне проверки PDI должно быть хорошим.

Необходимо иметь достаточное количество инструментов, оборудования и вспомогательных материалов:

| № | Наименование | Примечание | Модель |
|---|---|---|---|
| 1 | Диагностический сканер | Диагностическое программное обеспечение должно поддерживаться в актуальной версии |   |
| 2 | Аппарат высокого давления для мойки горячей и холодной водой | В холодных регионах обязательно должна быть горячая вода |   |
| 3 | Пылесос | Промышленного назначения |   |
| 4 | Прибор для проверки аккумуляторной батареи | Должен соответствовать требованиям метрологической калибровки |   |
| 5 | Зарядное устройство для аккумуляторной батареи | Постоянное напряжение, регулируемый ток |   |
| 6 | Насадка для подкачки шин с манометром | Должен соответствовать требованиям метрологической калибровки |   |
| 7 | Стандартный ручной инструмент | Должен соответствовать требованиям метрологической калибровки |   |
| 8 | Комплект защиты из 7 предметов (защита салона и кузова) | Комплект из трёх предметов для защиты крыльев и передней части кузова, комплект из четырёх предметов для защиты салона (чехол руля, чехол сиденья, коврик, чехол рычага) |   |
| 9 | Очиститель для кожи | Для очистки кожи | Специальный очиститель для кожи |
| 10 | Обычное моющее средство | Для очистки материалов из ПВХ и инженерного пластика ABS |   |

Необходимая документация для PDI: «Технология PDI», «Контрольный лист PDI», руководство пользователя. Во время работы обязательно надевать чистые перчатки и рабочую одежду.

**Примечание:**

**Автомобиль, проходящий PDI, должен быть новым автомобилем, принятым дилерским центром с положительным результатом приёмки.**

**Заблаговременно составьте план проведения PDI: рекомендуется проводить PDI в течение 48 часов до передачи автомобиля (если после проведения PDI прошло более 48 часов без передачи автомобиля, PDI необходимо провести повторно; PDI не может проводиться в день передачи автомобиля).**
